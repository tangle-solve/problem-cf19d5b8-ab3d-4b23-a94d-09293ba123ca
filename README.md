### ALGO-000245: Interoperable formal library of complexity reductions
- **Subfield:** Experimental algorithms, benchmarks, infrastructure, and funding
- **Open:** Build a versioned library of machine-checked reductions whose certificates record the source and target problems, promise conditions, computational model, encoding, and exact resource overhead.
- **Status:** Proposed engineering target, not a claim that formalized reductions do not exist. The challenge is interoperable coverage and auditable composition across theorem provers and models.

- **Why:** Would prevent incorrect reuse of reductions and support trustworthy automated complexity research.
